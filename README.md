# Machine Learning Lab Programs

Medium-length Python programs for the ML lab (external), one file per task.
All use built-in scikit-learn datasets, so they run standalone.

## How to run
```
pip install -r requirements.txt
python task01_pandas_import_export.py
```
(Programs with plots open a window via `plt.show()`.)

## Tasks
| File | Task |
|------|------|
| task01_pandas_import_export.py | Import/export data using Pandas (CSV, Excel, JSON) |
| task02_data_preprocessing.py | Data preprocessing (missing values, encoding, scaling, split) |
| task03_pca.py | Dimensionality reduction using PCA |
| task04_visualization.py | Data visualization (line, bar, hist, scatter, box, heatmap) |
| task05_linear_regression.py | Simple & Multiple Linear Regression |
| task06_logistic_regression.py | Logistic Regression |
| task07_decision_tree.py | Decision Tree classification + classify new sample |
| task08_naive_bayes.py | Naive Bayes (GaussianNB) |
| task09_knn.py | K-Nearest Neighbours classification |
| task10_backpropagation.py | Back Propagation neural network (MLP) |
| task11_randomforest_boosting.py | a) Random Forest  b) Boosting (AdaBoost) |
| task12a_kmeans.py | K-Means clustering (with & without libraries) |
| task12b_birch.py | BIRCH clustering algorithm |

**Reference:** Python Machine Learning — Sebastian Raschka, O'Reilly.
